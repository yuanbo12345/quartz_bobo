## 拉直函数
```python
def num_flat_features(self,x):
        size = x.size()[1:]
        num_features = 1
        for s in size:
            num_features *= s
        return num_features
```
1. 这个函数定义在CNN卷积和全链接层之间，也就是将多张特征图合并拉直的时候使用
2. 将多维拉直合并
3. 这个函数属于前向传播的调用函数之一
4. 注意调用的时候加上`self.`类属性
### 替代函数接口
```python
x = torch.flatten(x,1)
```
1. 这个函数就可以替代上面的拉直计算，注意传入参数1就是代表自适应计算
2. <mark style="background: #FF5582A6;">重要</mark>

### 神经网络类中的方法定义
1. `class LetNet():`定义一个类时先填入继承的父类，注意括号前面的时类名称，别忘记冒号指出，还有就是首行缩进非常重要
2. 类初始化`def __init__(self):`这就是构造函数，构造函数要处于类的一部分，所有要加入`self`自参数
3. `super().__init__()`不用加self以及冒号
4. 只有前向传播函数中才会进行传递和计算，构造函数中是不会的

## 优化器
### 常规优化器代码
```python
net.parameters() 
```
1. 这个函数用在优化器函数中作为传入参数使用
2. 作用是把所有构造的张量都拿出来进行训练
3. 记住一定要先实例化成一个模型，模型构造完了接着就实例化`model = letnet()`即可
4. 这个函数调用的时候用对实例化进行，所以是`model.parameters()`

## 神经网络训练模型
```python
def train(epoch):                       # ① 把当前 epoch 序号传进来，方便打印/调度
    model.train()                       # ② 开启“训练模式”，影响 Dropout/BN 层行为
    running_loss = 0.0                  # ③ 累计 100 个 batch 的平均 loss，方便打印
    for i, data in enumerate(train_loader):  # ④ i=0,1,2…  data=(batch_imgs, batch_labels)
        inputs, labels = data           # ⑤ 拆包，inputs 形状 [N,1,28,28]，labels 形状 [N]
        
        optimizr.zero_grad()            # ⑥ 清空梯度，防止梯度累加（PyTorch 默认累加）
        outputs = model(inputs)         # ⑦ 前向传播，outputs 形状 [N,10]
        loss = criterion(outputs, labels)  # ⑧ 计算交叉熵或你指定的损失
        loss.backward()                 # ⑨ 反向传播，求所有参数的梯度
        optimizr.step()                 # ⑩ 按优化器规则更新参数（SGD/Adam…）
        
        running_loss += loss.item()     # ⑪ 把 Tensor 里的标量取出来再累加，避免显存堆积
        if i % 100 == 99:               # ⑫ 每 100 个 batch 打印一次
            print('[%d, %5d] loss: %.3f' %
                  (epoch + 1, i + 1, running_loss / 100))
            running_loss = 0.0          # ⑬ 清零，准备下一个 100 batch

```

1. `inputs,labels = data`就是把前边定义的训练集中的输入和标签输入变量（赋值）
2. 第一个循环的作用就是将训练集中的数据按照前边规定的批次，一个批次的放入到`data`变量中
3. `running_loss += loss.item()`这个语句的作用就是把“这一批次的 loss 值”从张量里抽出来变成普通数字，加到计数器上，方便后面求平均
#### 条件打印解析
1. `if i % 100 == 99`这句话的作用是<mark style="background: #FF5582A6;">每100个batch打印一次</mark>
2. ![[image-257.png]]
3. 所以是现有占位符，然后才是替代的数值表达
4. `running_loss += loss.item()`这个语句除了将计算得到的损失函数值从张量提取变成数值类型之外，还有就是将一个批次的所有损失值都累加到一起的作用
5. 区分epoch和batch，epoch是指将整个数据集进行扫几遍，batch就是将数据集中的数据分几次输入
6. 前边Dataloader中设定的batch就是指将数据分几个批次输入到训练集变量中，而后边循环打印中的batch是指多少个批次打印一次损失值
