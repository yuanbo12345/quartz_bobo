# 物理约束的条件U-Net：针对RTX 3060硬件与1周训练周期的喷雾图像生成实验方案

## 1. 项目背景与核心目标

### 1.1. 背景
在当前受限的计算资源（单张RTX 3060显卡）和时间预算（1周）下，我们需要放弃追求极致视觉保真度的扩散模型，转而寻求一个能够在保证关键物理特征准确性的前提下，高效完成训练并投入使用的替代方案。

### 1.2. 核心目标
开发一个基于U-Net架构的深度学习模型，其输入为**工况参数**（如喷射压力、环境压力等）和**时间** `t`，输出为对应的喷雾宏观图像。该模型的核心要求是：

*   **物理准确性优先**：生成图像的**宏观物理特征**（喷雾贯穿距、喷雾角、喷雾宽度）必须与真实图像高度一致，误差需控制在可接受范围内。
*   **硬件与时间可行性**：必须能在RTX 3060 (12GB VRAM)上于一周内完成完整训练。
*   **牺牲视觉细节**：允许生成的图像在纹理、清晰度等方面有所欠缺，只要不影响对宏观物理特征的判断即可。

---

## 2. 方案设计原理：为何选择修正版U-Net

### 2.1. 放弃扩散模型的原因
*   **计算资源消耗过大**：扩散模型需要多步迭代去噪，训练过程极其耗时耗力，无法满足1周的训练周期要求。
*   **显存需求高**：即使使用较小的网络，其训练过程对显存的需求也远超RTX 3060的能力范围，容易导致OOM错误。

### 2.2. U-Net的优势
*   **单次前向传播**：U-Net从输入直接生成输出，推理和训练速度极快。
*   **轻量级架构**：标准的U-Net结构相对简单，可以通过调整通道数和层数，在RTX 3060的显存限制下进行优化。
*   **成熟稳定**：U-Net是计算机视觉领域的经典架构，相关库和教程丰富，调参难度低。

### 2.3. 关键创新：物理约束损失函数
为了弥补U-Net在“物理真实性”上的不足，我们引入了**可微分的物理特征提取模块**作为损失函数的一部分。这使得模型在训练过程中被强制学习如何生成符合物理规律的图像，而非仅仅模仿像素。

## 3. 模型架构详述

### 3.1. 整体框架
模型是一个典型的**编码器-解码器**结构，即U-Net。

```
           Input: [Condition Vector, Time]
                            ↓
                    [U-Net Encoder]
                            ↓
             [Bottleneck / Latent Space]
                            ↓
                    [U-Net Decoder]
                            ↓
                  Output: Spray Image
```

### 3.2. 条件注入机制
我们将工况参数和时间 `t` 作为额外的条件信息注入到U-Net中，有两种主流实现方式：

#### 3.2.1. 方法A：条件通道拼接 (Conditional Channel Concatenation)
*   将工况参数和时间经过一个小型MLP（例如：2层全连接层，ReLU激活），输出一个固定长度的特征向量（例如，长度为32或64）。
*   将这个特征向量扩展成一个与U-Net某一层特征图空间尺寸相同的张量（通过`repeat_interleave`或`tile`操作）。
*   将这个扩展后的条件张量与对应层的特征图在**通道维度**上进行拼接。通常选择在编码器的每一层和解码器的每一层都进行注入。

#### 3.2.2. 方法B：条件交叉注意力 (Conditional Cross-Attention) （推荐，但略复杂）
*   同样先将条件信息处理成一个特征向量。
*   在U-Net的每一层后，添加一个Cross-Attention模块。该模块接收来自前一层的特征图作为Query，并以条件向量作为Key/Value，计算出一个注意力权重图，然后将其应用于特征图。
*   这种方法更灵活，能更好地让网络根据条件聚焦于不同区域，但实现起来稍复杂。

**初步建议**：对于快速验证，采用**方法A**（条件通道拼接）。它简单、有效，且易于调试。

### 3.3. 网络规模配置 (针对RTX 3060)
为了确保在12GB显存下顺利训练，我们建议采用以下配置：

*   **初始通道数**：`init_channels = 32`
*   **最大通道数**：`max_channels = 256`
*   **下采样次数**：`num_downsamplings = 4` (即4次降采样，总共有5层编码器和5层解码器，共10层)
*   **激活函数**：`ReLU`
*   **归一化**：`BatchNorm`
*   **输出激活**：`Sigmoid` (如果图像数据已归一化到[0, 1]区间)

这个配置可以在128x128或256x256分辨率的图像上运行，显存占用约在8-10GB之间，留有余地。

## 4. 数据准备流程

### 4.1. 数据集清单生成
首先，需要创建一个包含所有图像路径、对应工况参数和时间的CSV文件。

1.  遍历所有图像文件夹（如 `images/2.0/视频数据/`）。
2.  解析每个文件名，提取工况参数和时间信息。
    *   例如，文件名 `A40D60-0.32-300K-50MPa-2.0MPacut_Rep_1_0167us_original_cropped.png` 中，可以解析出：
        *   `喷射压力`: 50 MPa
        *   `环境压力`: 2.0 MPa
        *   `温度`: 300 K
        *   `时间`: 0.167 us
    *   将这些信息写入 `dataset_manifest.csv` 文件。
3.  确保所有图像大小一致（如256x256），如果不一致，则进行裁剪或缩放。

### 4.2. 数据预处理
*   **图像标准化**：将图像像素值归一化到 `[0, 1]` 或 `[-1, 1]` 区间。
*   **条件归一化**：对工况参数（如压力、温度）进行标准化（Z-score或Min-Max），使其分布均值为0，方差为1，或缩放到 `[0, 1]` 区间。
*   **数据增强**：（可选）由于数据量可能有限，可以考虑加入轻微的旋转、平移或亮度调整，以提高模型鲁棒性。

### 4.3. 数据加载器
使用PyTorch的 `DataLoader` 创建训练集和验证集。批次大小 (`batch_size`) 建议设置为 `8` 或 `16`，以确保显存不溢出。

## 5. 物理特征提取模块设计 (核心难点)

这是整个方案成功与否的关键。我们需要一个模块，能够从一张图像中自动、可微分地计算出关键的物理参数。

### 5.1. 关键物理参数定义
*   **喷雾贯穿距 (Penetration Length)**：从喷嘴中心点到喷雾前锋边缘的最大距离。
*   **喷雾角 (Spray Angle)**：喷雾边缘的两个切线之间的夹角。
*   **喷雾宽度 (Width at Distance)**：在离喷嘴中心特定距离处（如`d=5mm`），喷雾的横向直径。

### 5.2. 提取算法设计 (以喷雾贯穿距为例)

#### 5.2.1. 原理
*   假设喷雾图像为灰度图，前景（喷雾）为亮区，背景为暗区。
*   我们可以将喷雾视为一个连通域。喷雾贯穿距就是从喷嘴位置开始，沿水平方向（假设喷嘴在左侧）延伸到最远亮像素的距离。

#### 5.2.2. 可微分实现 (PyTorch伪代码)
```python
import torch
import torch.nn as nn

class SprayFeatureExtractor(nn.Module):
    def __init__(self, nozzle_position_x=0, nozzle_position_y=128):
        super(SprayFeatureExtractor, self).__init__()
        self.nozzle_x = nozzle_position_x
        self.nozzle_y = nozzle_position_y

    def forward(self, image):
        # image: [B, C, H, W], 假设C=1, 归一化到[0,1]
        B, C, H, W = image.shape

        # 1. 二值化阈值 (这是一个可学习的参数，或者用固定阈值)
        threshold = 0.5
        binary_image = (image > threshold).float() # [B, 1, H, W]

        # 2. 计算喷雾贯穿距
        # 假设喷嘴在图像左侧中间位置 (nozzle_x=0, nozzle_y=H//2)
        # 我们需要找到每一行中最右边的亮像素，然后取平均值或最大值
        # 为了可微分，我们不能用argmax，需要用加权平均。
        
        # 在每一行上，计算每个像素位置的“贡献”
        x_coords = torch.arange(W, device=image.device).reshape(1, 1, 1, W) # [1, 1, 1, W]
        x_coords = x_coords.expand(B, 1, H, W) # [B, 1, H, W]
        
        # 对每一行，计算加权平均的x坐标
        row_sum = torch.sum(binary_image, dim=3, keepdim=True) # [B, 1, H, 1]
        weighted_sum = torch.sum(binary_image * x_coords, dim=3, keepdim=True) # [B, 1, H, 1]
        
        # 避免除零
        avg_x_per_row = torch.where(row_sum > 0, weighted_sum / (row_sum + 1e-8), torch.zeros_like(weighted_sum))
        
        # 取最大值作为贯穿距 (这里简化，实际应用中可能需要更复杂的逻辑)
        penetration_length = torch.max(avg_x_per_row) - self.nozzle_x # [B, 1, H, 1]
        
        # 3. 计算喷雾角 (简化版本)
        # 找到顶部和底部的边界
        top_boundary = torch.max(torch.argmax(binary_image, dim=2, keepdim=True), dim=3, keepdim=True)[0]
        bottom_boundary = torch.min(torch.argmin(binary_image, dim=2, keepdim=True), dim=3, keepdim=True)[0]
        spray_angle = torch.atan2((bottom_boundary - top_boundary), penetration_length) * 2 # 简化公式
        
        return {
            'penetration_length': penetration_length.squeeze(),
            'spray_angle': spray_angle.squeeze(),
            # ... 其他参数
        }
```

> **重要提示**：上述代码仅为示意，实际实现会更加复杂。您可能需要结合OpenCV的形态学操作（如腐蚀、膨胀）来精确提取轮廓，然后使用可微分的近似方法（如软argmax）来计算距离和角度。这是一个需要重点攻克的技术难点。

## 6. 损失函数设计

### 6.1. 总损失函数
`L_total = w1 * L_pixel + w2 * L_physics`

### 6.2. 像素损失 (`L_pixel`)
*   **函数**：`L1Loss` 或 `MSELoss`
*   **作用**：保证图像的基本形状和结构正确。
*   **权重**：`w1 = 1.0` (初始值，可根据效果调整)

### 6.3. 物理损失 (`L_physics`)
*   **函数**：`MSELoss` 或 `L1Loss`
*   **作用**：强制模型学习正确的物理参数。
*   **计算方式**：
    *   使用上面开发的 `SprayFeatureExtractor` 模块，分别计算生成图像和真实图像的物理参数。
    *   计算它们之间的差异。
    *   例如：`L_physics = MSE(phys_pred, phys_gt)`
*   **权重**：`w2 = 10.0` 或更高。这是关键！我们必须给物理损失一个非常高的权重，才能确保模型真正关注物理特性。

### 6.4. 训练策略
*   **学习率**：初始学习率 `lr = 0.0001`，使用CosineAnnealing调度器。
*   **优化器**：`AdamW`。
*   **梯度裁剪**：防止梯度爆炸。

## 8. 预期结果与风险评估

### 8.1. 预期结果
*   成功训练出一个能够在RTX 3060上运行的模型。
*   生成的图像可能不够锐利，但其宏观物理特征（贯穿距、喷雾角）与真实图像的误差控制在5%以内。
*   模型在1周内完成训练并达到可用状态。

### 8.2. 主要风险与应对措施
*   **风险1：物理特征提取模块难以实现可微分。**
    *   **应对**：初期可以使用非可微分的方法（如OpenCV）计算物理参数，用于监控和评估。待模型初步收敛后，再逐步替换为可微分版本。
*   **风险2：模型无法收敛或物理误差过大。**
    *   **应对**：尝试降低网络复杂度，或增加物理损失的权重 `w2`。也可以尝试先训练一个只预测物理参数的回归模型，作为辅助任务。
*   **风险3：显存不足。**
    *   **应对**：减小批次大小 (`batch_size`) 至4，或降低图像分辨率至128x128。
