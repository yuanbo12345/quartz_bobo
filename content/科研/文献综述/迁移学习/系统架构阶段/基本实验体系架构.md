## 源工况模型训练程度
👉 **结论：必须训练到收敛且不过拟合**，即：
- 损失函数趋于平稳
- 验证集性能（RMSE / MAE / R²）稳定，不再提升
- 防止训练集RMSE很低，验证集RMSE却劣化

---
### 📌 二、为什么要这样设定？
- 如果训练不到收敛 → 迁移过去效果差，目标工况预测值误差大
- 如果过拟合 → 源工况训练得很好，但泛化性差，迁移过去效果不稳定
**迁移学习本质依赖源任务模型的良好泛化能力**，所以要合理停在**收敛不过拟合点**
![[image-96.png|627x317]]
### 四、具体训练流程推荐

> 📌 **建议用早停机制（EarlyStopping）+ LearningRate调度**

#### 📊 训练过程：

1. 每epoch计算训练损失和验证损失
    
2. 如果验证损失连续10个epoch没有下降 → 停止训练
    
3. 或者验证RMSE ≤ 工程容忍阈值（比如燃烧出口温度误差 ≤ 5 K）
    

#### 📌 设置初始学习率（如 0.001），验证损失降低不明显时，自动降低学习率（LR Scheduler）

---

## 🎯 1️⃣ 源工况数据集上训练基础模型

- **输入数据**：源工况仿真数据集
    
- **模型结构**：比如 GNN / MLP / LSTM
    
- **训练目标**：预测燃烧室出口温度/NOx排放/压力振荡等指标
    
- **损失函数**：一般用 MSE 或 RMSE
    
- **评价指标**：RMSE、MAE、R²
    
- **训练停止条件**：
    
    - 验证集RMSE不再下降（early stopping）
        
    - 或到达最大epoch
        

✅ 最后保留：

- 源工况模型参数权重
    
- 验证集上最佳模型权重
    

---

## 🎯 2️⃣ 定义迁移学习策略

常用迁移策略👇：

|策略|操作方法|
|---|---|
|**Fine-tuning**|源工况全部权重迁移 → 目标工况继续训练|
|**冻结底层迁移**|冻结前N层（一般是特征提取层） → 只训练后面几层|
|**特征提取迁移**|源工况训练模型 → 目标工况提特征 → 新模型学习特征到指标映射|

---

## 🎯 3️⃣ 将源工况模型权重迁移到目标工况模型

### 📌 具体做法：

- **相同结构**：保持网络结构一致
    
- **加载源工况权重**：比如 `model.load_state_dict()` 或 `load_weights()`
    
- **冻结部分层（按策略）**：
    
    - Fine-tuning：不冻结，所有层可训练
        
    - 冻结底层：`for param in model.layer1.parameters(): param.requires_grad = False`
        
    - 特征提取：提特征部分不训练，只用目标工况数据学映射部分
        

---

## 🎯 4️⃣ 目标工况数据微调

### 📌 微调目标：

让模型在目标工况数据上预测能力最优，但保留源工况的泛化特性

### 📌 微调内容：

|部分|操作|
|---|---|
|**学习率**|调小，例如源工况0.001 → 目标工况0.0001|
|**训练层数**|按迁移策略冻结或释放|
|**batch size**|小样本建议小一点（16-64）|
|**loss**|保持RMSE或MSE|
|**优化器**|Adam 或 AdamW，L2正则防过拟合|

### 📌 微调停止条件：

- 验证集RMSE连续N次迭代无下降（例如10个epoch）
    
- 或者达到最大epoch（比如200）
    

---

## 🎯 5️⃣ 微调效果评估

### 📌 评估指标：

- **RMSE**（Root Mean Squared Error）
    
- **MAE**（Mean Absolute Error）
    
- **R²**（决定系数）
    
- **训练耗时**
    

### 📌 停止微调判断：

- 验证集RMSE不再下降
    
- 或者达到阈值（比如RMSE < 目标设定值，例：RMSE < 2.0K）
    
- 或者R² ≥ 0.98
    

---

## 🎯 6️⃣ 在目标工况测试集上预测

### 📌 流程：

- 用微调好的模型，对目标工况的测试集数据预测
    
- 计算预测值 vs 实测值的
    
    - **RMSE**
        
    - **MAE**
        
    - **R²**
        
- 绘制预测结果残差图、误差分布图、收敛曲线
    

---

## 🎯 7️⃣ 做对比实验

| 实验类型                 | 模型/策略                       |
| -------------------- | --------------------------- |
| **不迁移（源模型直接预测目标工况）** | 源模型直接预测                     |
| **Fine-tuning迁移**    | 源模型权重 → 目标工况继续训练            |
| **冻结层迁移**            | 冻结前N层，只训练高层                 |
| **特征提取迁移**           | 提取源模型特征 → 新头部回归器            |
| **常规方法**             | MLP / LSTM / SVR / RF / GPR |
实验流程图
```swift
源工况数据 → 源工况模型训练 → 模型迁移 → 目标工况数据微调 → 测试预测 → RMSE/MAE对比 → 迁移策略/常规方法对比 → 结论
```

## 总结：核心点记住👇

- **微调内容**：主要是学习率降低 + 按策略冻结层 + 小batch训练
    
- **微调停止标准**：验证集RMSE连续不下降 + R² ≥ 0.98 或 RMSE < 目标阈值
    
- **迁移策略**：Fine-tuning / 冻结迁移 / 特征提取迁移
    
- **对比对象**：常规ML方法（MLP、LSTM、SVR、RF）
