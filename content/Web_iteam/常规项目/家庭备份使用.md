# 📚 家用服务器架构手册：图书/备份/内网穿透服务（Docker 版）

## 🧰 一、系统概要

- 操作系统：Ubuntu 20.04+/22.04+
    
- 服务类型：家庭服务器（固定IP或已能进入内网穿透的网络环境）用
    
- 部署方式：Docker + Docker Compose
    

## 🌐 二、服务架构规划

```
公网/本地访问
     |
【 Dashy 总控面板 】  <--- 整合全部服务管理
     |
  │      ├──【 BookLore 电子图书库 】
     |      │
     |      ├──【 Duplicati 自动化备份】
     |      │
     |      └──【 EasyTier 内网穿透 】（替代 reseed / cloudflared）
```

## 🔧 三、Docker 环境安装

```bash
sudo apt update && sudo apt install -y docker.io docker-compose-plugin
sudo systemctl enable docker && sudo systemctl start docker
docker version
```

## 🗂️ 四、项目目录结构

```
/home/ubuntu/book-server/
├── docker-compose.yml
├── dashy/              # 总控面板数据目录
├── booklore/           # BookLore 数据
├── duplicati/          # Duplicati 配置文件
├── easytier/           # EasyTier 数据/配置
```

## 🔌 五、docker-compose.yml 配置

```yaml
version: "3.8"
services:

  dashy:
    image: lissy93/dashy:latest
    container_name: dashy
    volumes:
      - ./dashy:/app/public
    ports:
      - "8080:80"
    restart: unless-stopped

  booklore:
    image: ghcr.io/adityachandelgit/booklore:latest
    container_name: booklore
    ports:
      - "4000:4000"
    volumes:
      - ./booklore:/app/data
    restart: unless-stopped

  duplicati:
    image: lscr.io/linuxserver/duplicati:latest
    container_name: duplicati
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Shanghai
    volumes:
      - ./duplicati/config:/config
      - /home/ubuntu/Documents:/source
      - /home/ubuntu/backups:/backups
    ports:
      - "8200:8200"
    restart: unless-stopped

  easytier:
    image: ghcr.io/easytier/easytier:latest
    container_name: easytier
    volumes:
      - ./easytier:/data
    ports:
      - "443:443"
    restart: unless-stopped
```

## 🚀 六、服务部署教程（含安全配置）

### 1. 📘 BookLore 部署教程

- 进入数据目录：`cd ~/book-server/booklore`
    
- 将书籍文件（epub/pdf/txt）放入此目录
    
- 启动服务：`docker compose up -d booklore`
    
- 默认访问端口：`http://your-ip:4000`
    
- 安全措施：
    
    - 不暴露公网端口4000，只通过 EasyTier 或反向代理访问
        
    - 使用 UFW 限制外部端口访问：`sudo ufw deny 4000`
        

### 2. 📂 Duplicati 部署教程

- 打开 Web UI：`http://your-ip:8200`
    
- 创建新备份任务：指定源 `/source`，目标 `/backups`
    
- 支持上传到远程云盘（如 OneDrive, S3, WebDAV）
    
- 安全措施：
    
    - 启用强密码（非空密码）管理界面
        
    - 选择 AES-256 端到端加密模式
        
    - 不暴露公网端口 8200，仅限局域网
        
    - 定期检查“日志”与“计划任务”是否按时执行
        

### 3. 🧅 EasyTier 部署教程

- 进入配置目录：`~/book-server/easytier`
    
- 启动后监听 443 端口，支持域名穿透与自定义访问路径
    
- 配置参考文件（`easytier.yaml`）：
    

```yaml
entry:
  path: "/hidden-entry"
  tls: true
  hostname: yourdomain.com
  target: http://localhost:8080
security:
  randomize-path: true
  log-level: warn
  firewall-mode: true
```

- 启动命令（如未使用 Compose）：`docker run -v $(pwd):/data easytier/easytier`
    
- 测试访问：`https://yourdomain.com/hidden-entry`
    
- 安全措施：
    
    - 使用伪装路径与域名隐藏真实服务端口
        
    - 支持自签名或 Let’s Encrypt 自动证书
        
    - 限制出口 IP，仅白名单允许访问
        

### 4. 🧭 Dashy 总控面板部署教程

- 进入 Dashy 目录：`~/book-server/dashy`
    
- 初次运行后会自动生成配置文件：`conf.yml`
    
- 可使用在线编辑器：`https://dashy.to/config`
    
- 安全措施：
    
    - 设置密码保护（配置 nginx 反代 + basic auth）
        
    - Dashy 本身禁用端口暴露，仅供反代使用
        

## 🌍 七、公网访问与内网穿透

- 使用 EasyTier 建立 TLS 入口点，防止 IP 暴露
    
- 使用动态 DNS 配置域名绑定
    
- 所有服务默认仅本地端口暴露，统一由 EasyTier 反代暴露 443
    

## 🛡 八、安全强化措施

1. UFW 防火墙配置：
    

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 443/tcp  # 仅开放 easytier 入口
sudo ufw enable
```

2. Docker 网络隔离：
    

```yaml
networks:
  private_net:
    driver: bridge
```

- 将所有服务绑定到 `private_net`，只有 EasyTier 可访问 8080、4000、8200
    

3. 目录权限加固：
    

```bash
sudo chown -R $USER:docker ~/book-server
sudo chmod -R 700 ~/book-server/*
```

4. 启用 AppArmor 或 SELinux 加强容器隔离
    
5. 安装 `fail2ban` 检测暴力攻击并自动封禁 IP

## 🧹 九、全部服务的清理卸载方法

当你需要彻底移除所有服务、数据和镜像，可以按以下方式操作：

### 1. 停止并移除容器

```bash
cd /home/ubuntu/book-server
docker compose down
```

### 2. 删除镜像

```bash
docker rmi ghcr.io/adityachandelgit/booklore
docker rmi lscr.io/linuxserver/duplicati
docker rmi ghcr.io/easytier/easytier
docker rmi lissy93/dashy
```

### 3. 删除挂载目录数据

```bash
sudo rm -rf ~/book-server
```

### 4. 清理无用网络、卷和镜像

```bash
docker system prune -a --volumes -f
```

### 5. 卸载 Docker（如不再使用）

```bash
sudo apt purge docker.io docker-compose-plugin
sudo rm -rf /var/lib/docker /etc/docker
```

⚠️ 清理操作**不可逆**，请提前备份重要数据！
