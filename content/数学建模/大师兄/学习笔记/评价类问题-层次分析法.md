### 构造两类判断矩阵
1. 第一类是关于不同方案层在不同准则之下的两两关系矩阵，如下![[image-122.png]]
2. 第二类是关于，不同准测层之间的两两权重关系矩阵，如下![[image-123.png]]
### 第三步根据查资料，或者实际情况，两两打分确定判断矩阵

### 第四步根据判断矩阵计算得到权重关系
1. 第一：根据不同的方案层在不同标准层下的判断矩阵计算得到不同方案在先相同标准下的权重![[image-124.png]]
2. 第二，根据不同方案层之间的判断矩阵计算得到不同方案层的权重
3. 第三，填入权重表中![[image-125.png]]相同标准下的不同方案曾权重是一行一行的填到权重表中，例如表中蓝色箭头这一行，就是上上图中计算的在景色的评价标准下得到的苏杭，北戴河，桂林的分别权重
4. 第四根据方案曾权重和评价标准权重乘积之和作为总的权重，填入表中
5. 第五，最后计算总权重的一致性即可

## 代码
```c
%% 层次分析法
% 只有非一致矩阵才需要一致性检验
% % 要先进行一致性检验，通过后才能求权重，我们这里为了方便讲解才放到了最后做的一致性检验

%% 获取判断矩阵
disp('请输入判断矩阵A')
A=input('A=');
[n,n] = size(A);

%% 方法1： 算术平均法求权重
Sum_A = sum(A); %将A矩阵按列求和
SUM_A = repmat(Sum_A,n,1);
Stand_A = A ./ SUM_A;

disp('算术平均法求权重的结果为：');
w1 = sum(Stand_A,2)./n;
disp(w1)

%% 方法2： 特征值法求权重
[V,D] = eig(A);
Max_eig = max(max(D));% 先按列求最大值，得到行向量，再从这个向量里面求最大值
[r,c]=find(D == Max_eig , 1);
disp('特征值法求权重的结果为：');
w2 = V(:,c) ./ sum(V(:,c));
disp(w2)
disp('两种方法的平均权值为：');
disp((w1 + w2) ./ 2);

%% 计算一致性比例CR
CI = (Max_eig - n) / (n-1);
RI=[0 0.0001 0.52 0.89 1.12 1.26 1.36 1.41 1.46 1.49 1.52 1.54 1.56 1.58 1.59];  %这里的RI最多支持 n = 15，注意检查！
% 这里n=2时，RI=0，我们为了避免分母为0，将这里的第二个元素改为了很接近0的正数
CR=CI/RI(n);
disp('最大特征值为:');
disp(Max_eig);
disp('一致性指标CI=');disp(CI);
disp('一致性比例CR=');disp(CR);
if CR<0.10
    disp('CR<0.10，该判断矩阵A的一致性可以接受!');
else
    disp('注意：CR >= 0.10，该判断矩阵需要进行修改!');
end
```
1. 比赛的时候AI改写一下就行
2. 上述代码中只需要改变RI值和输入的判断矩阵就行，注意不同层计算得到权重在权重表中的位置一定是不同的别填写错误
3. 注意输入的矩阵形式怎么去写
```c
% 输入的矩阵形式
A = [1 2 5; 1/2 1 2; 1/5 1/2 1]
```
