# 总体流程
1. 通过标定图像计算每个图像的平均灰度值，然后和该标定图像下的刀口偏移量一起通过插值方法构成刀口偏移量和灰度值的函数关系（灰度值归一化之后的）
![[image-318.png]]
2. 选定参考灰度值（一般选择光强为40%最大光强的刀口位置）对应的标定图像作为参考图像【软件中需要输入的是参考图像的序号】
3. 将待测对称温度场放到待测的流场区域，固定好温度场的长度（温度场厚度），然后在刀口为200微米偏移量下，分别拍摄温度场固定温度为22，24，26，55，60，63，78，85，90，92，95，109，137，153，159摄氏度下拍摄照片
![[image-319.png]]
4. 对每张测试图像分别计算其与参考图像在每个对应的像素点上产生的灰度值，然后依据灰度值得到相应的刀口偏移量，根据测试图像和参考图像在每个对应像素点的各自刀口偏移量计算测试图像像素点处的刀口未遮挡光源像面积与参考图像中刀口未遮挡官员面积之差，<mark style="background: #FF5582A6;">作为光线偏移量</mark>
![[image-320.png]]
![[image-321.png]]
5. 由于加进入温度场之后光线经过温度场之后会造成折射率发生变化，折射率的变化会造成在Y方向产生偏移角，偏移角的产生会造成光线由参考图像在Y方向发生偏移，所以积分的时候对上面计算得到的每个像素点对应的偏移量积分区域是指从参考图像的刀口步进量到测试图像对应像素点的刀口步进量，是对每个像素点的光线偏移量都进行一次对应的积分。<mark style="background: #FF5582A6;">这个对每个像素点的光线偏移量进行积分的过程就是步骤4中进行面积差计算的过程</mark>
![[image-322.png]]

> [!NOTE] 注意
> 1. 积分公式中的a代表的是折射角为$θ_y$ 的时候对应的光线偏移量，所以需要积分区域是刀口步进量之间，这样积分后就是对应不同刀口步进变化量下的实际光线偏移量

1. 带入计算即可得到测试图像每个像素点的密度值，然后依据密度值代入公式即可得到每个像素点对应的温度值，然后对图像的每个像素点都进行步骤4，5的计算即可得到整个测试图像的温度场

- 温度场计算代码

```matlab
function TemperatureSingleButtonPushed(app, event)
    % 获取掩码和文件路径信息
    thisMask=app.imthisMask;
    filename=app.imfilenameTemp;
    path=app.impathTemp;

    % 获取测量参数
    % 光源半径（转换为米）
    rad_light=app.LightsourceradiusEditField.Value/1e6;
    % 焦距2
    f2=app.f_2EditField.Value;
    % 参考密度
    rho0=app.rho_0EditField.Value;
    % 参考温度
    T0=app.T_0EditField.Value;
    % 光学常数K
    K=app.KEditField.Value;
    % 厚度比例
    ratio=app.ThicknessratioEditField.Value;
    % 有效厚度 = 光源半径 × 厚度比例
    L=rad_light*ratio;
    % 缩放因子（用于像素到毫米的转换）
    sf=app.SfEditField.Value;

    % 计算光源面积
    A_l=pi*rad_light*rad_light;     % m²
    % 计算光学参数dS
    dS=K*f2*L;

    % 提取文件扩展名
    suffix = filename(end-3:end);
    figure(app.TemperatureBySchlierenUIFigure);

    % 根据文件扩展名读取图像
    switch suffix
        case '.im7'
            I_davis = readimx(filename);
            I_matrix=I_davis.Data;
            I_matrix=I_matrix';
            I_matrix_flip = I_matrix(end:-1:1,:,:);
        otherwise
            I_matrix = imread(filename);
            I_matrix_flip = I_matrix(end:-1:1,:,:);
    end

    % 归一化图像强度到[0,1]
    I=double(I_matrix)/65535;

    % 使用插值进行拟合
    % x: 平均强度差
    x=app.imImean;
    % v: 刀口位置
    v=app.impos;
    % 合并数据
    data=[x,v];
    % 按平均强度差排序
    data_order=sortrows(data);
    % 创建插值函数F，将强度差映射到刀口位置
    F = griddedInterpolant(data_order(:,1),data_order(:,2));

    % 计算强度差
    % 获取参考图像
    I_ref=app.imIref;
    % 计算强度差
    I_grad = I-I_ref;
    % 将掩码外的像素设为0
    I_grad(~thisMask)=0;

    % 计算刀口位置
    % 使用插值函数将强度差转换为刀口位置
    pos_K= F(I_grad);
    % 限制刀口位置范围（大于光源直径时设为0）
    pos_K(pos_K/(rad_light*1e6)>2)=0;
    % 限制刀口位置范围（小于0时设为0）
    pos_K(pos_K<0)=0;

    % 计算面积变化
    % 调用面积变化计算函数，输入为归一化的刀口位置
    [dis2Area] = calDeltaAfunc(app,pos_K/(rad_light*1e6));
    % 将掩码外的面积变化设为0
    dis2Area(~thisMask)=0;

    % 计算温度场
    % 使用光学模型计算温度场：T = T0 / (1 - (dis2Area*A_l*rho0/dS))
    T=T0./(1-(dis2Area*A_l*rho0./dS));
    % 将掩码外的温度设为NaN
    T(~thisMask)=nan;
    % 将负温度值设为参考温度
    T(T<0)=T0;

    % 清空绘图坐标轴2
    cla(app.UIAxes2);
    % 使用中值滤波对温度数据进行平滑处理
    T_smoothed = medfilt2(T,[10,10]);
    % 以像素到毫米的缩放比例显示温度场
    h=imagesc(app.UIAxes2,(1:size(T,1))./sf,(1:size(T,2))./sf,T_smoothed);
    % 设置透明度，NaN区域透明
    set(h,'alphadata',~isnan(T_smoothed))
    axis(app.UIAxes2,'equal')  % 设置坐标轴相等比例
    axis(app.UIAxes2,'tight')  % 设置坐标轴范围为数据范围
    xlabel(app.UIAxes2,'x [mm]','FontSize',12)  % x轴标签（毫米）
    ylabel(app.UIAxes2,'y [mm]','FontSize',12)  % y轴标签（毫米）
    title(app.UIAxes2,'Temperature')  % 图像标题
    colormap(app.UIAxes2,'hot')  % 设置为热点色彩映射
    colorbar(app.UIAxes2,"east")  % 在右侧显示颜色条
    box(app.UIAxes2,"on")  % 显示边框
end
```
