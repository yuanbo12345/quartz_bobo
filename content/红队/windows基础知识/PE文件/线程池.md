## 线程池的典型结构
```
                ┌────────────────────┐
                │   任务队列（FIFO）  │  ← 任务不断进来（客户请求、数据处理等）
                └────────────────────┘
                           ↓
                 ┌──────────────────┐
                 │    线程池管理器   │
                 │  - 线程创建/复用  │
                 │  - 分发任务给线程 │
                 └──────────────────┘
                        ↓↓↓↓↓
     ┌────────┬─────────┬─────────┬────────┐
     │线程T1   │ 线程T2   │ 线程T3   │ ...  │ ← 固定数量的线程等待任务
     └────────┴─────────┴─────────┴────────┘

```
