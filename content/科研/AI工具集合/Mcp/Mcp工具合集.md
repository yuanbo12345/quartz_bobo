# Mcp工具任务单
## 所需工具的要求
1. 在cursor中解析各种格式的文本文档能给大模型进行识别
2. 在cursor中能集合大模型进行高级推理思考，分析用户需求将其分步骤的
3. 实现对系统中的各类文件进行操作，常规办公格式文件，删除，创建，文字级精确修改，替换，多文本文件合并，格式尽量不变，根据用户面临提取文件中的关键内容，进行概述
4. 将笔记内容和用户需求将文字进行符合用户需要的整合，关键整合，修订格式，重点突出
5. mcp的管理方法，查找选择方法
6. 浏览器自动操作，表单自动填写，多文件网页处理，内容聚合搜集形成概述，文件下载之类的
7. 系统级的文件整理，主要是办公类文件根据名称和类型定期整理存放，自动完成

## 工具列表
### 文本文档整合修改类工具
#### 要求
实现对主机中各种格式的文本文件进行概述，根据用户需要进行关键处的文字内容提炼合并，文字级的精确修改替换，多文本文件的文字级合并处理生成符合用户需求的文件

#### 工具推荐
1. Continue插件，cursor自带
2. https://github.com/Dicklesworthstone/ultimate_mcp_server 的mcp

### 高级推理思考类工具
#### 要求
实现对我给出的命令进行多方面的分析推理借助大模型，然后自习确定用户意图之后，将复杂过程详细划分成科学精确一定能被大模型完成的任务，提交给大模型具体操作，这种开源的高级推理思维mcp，支持cursor，使用cursor自带的大模型

简单讲：就是我给出一个问题，它可以通过大模型在对我的问题经过多角度的分析和充分的调查最新权威的资料之后，给我一个最有效能完美解决问题同时又更具有创新性的具体解决问题的方案，然后分计划给我一步步的展示出计划的方案，并且每一步的实现都是真实有效的同时经过反复推理和验证的，最终能够充分调用大模型解决能解决的必要问题
