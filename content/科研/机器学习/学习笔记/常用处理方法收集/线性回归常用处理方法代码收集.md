### 列中字符串替换
```python
df['Room Number'] = df['Room Number'].replace({'tur':1,'rut':2})
```
1. 注意关键函数就可以，`df[''].replace`中的`.replace`函数就是实现将该列中的某些字符串替换成其他的
2. `.replace({})`注意这个函数中需要替换的字符串要写到大括号里面
3. `'A':1,'B':2`替换的字符串引号引起来就像，冒号指向需要替换成什么

### 列元素权重统计
```python
count_column_x = len(df[df['Room Number'] == 'x'])
count_column_y = len(df[df['Room Number'] == 'y'])
count_xy = count_column_x/count_column_y
```
1. `len()`函数就是计算字段长度
2. `df['Room Number']`就是取列名是这个的该列所有元素
3. `df[df['Room Number'] == 1]`最里面那个大括号中的作用就是判定该列中元素等于什么的都取出来，然后再外面嵌套一个大括号就是指该元素对应的所有所有列名下的集合数据集

## 机器学习库常用处理方法模板
### 预处理阶段
#### 标准化
```python
from sklearn.preprocessing import StandardScaler

df['Room Number'] = StandardScaler().fit_transform(df['Room Number'].values.reshape(-1,1))

```

1. `StandarScaler()`函数就是标准化函数所在的库；`.fit_transform()`函数就是标准化库的中压缩标准化方法，调用的时候记住千万别分开
2. `df['Room Number']` `.values`就是指这个df数据库中room<mark style="background: #FF5582A6;">所在列的所有数据</mark>，不包括列名称，所以`.values`就是指取所有数据的值
3. `.reshape(-1,1)`就是指将上面提取的数据变成压缩标准化函数所需要的形状，`(-1,1)`就是把形状变成一列
