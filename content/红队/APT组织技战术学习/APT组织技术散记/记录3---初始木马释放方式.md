#### 相关技术原理
##### 1---使用invoke-webrequest命令以从指定的url链接下载文件
`Invoke-WebRequest` 是 PowerShell 的一个内置命令（cmdlet），主要用于发送 HTTP/HTTPS 请求，获取网页内容或下载文件，可以使用 `-OutFile` 参数指定下载文件的存储路径。

- **正常情况下**：该命令常用于合法的自动化任务（如脚本下载更新、获取网页内容等），不会触发安全警报。
- **恶意利用时**：如果攻击者使用该命令从外部服务器下载恶意文件，现代杀毒软件和EDR（Endpoint Detection and Response）系统可能会检测到异常行为并发出警报。

##### 4---pe文件的执行
**"白+黑"（白加黑，White+Black）** 是指**利用合法（白）的进程或文件，来执行恶意（黑）的代码**，从而绕过安全软件检测。

- **"白"（White）**：合法的 Windows 进程、系统 DLL、可信软件（如 `rundll32.exe`、`msiexec.exe`、`explorer.exe`）。
- **"黑"（Black）**：攻击者植入的恶意 DLL 或代码。

白加黑本质就是恶意代码的一种加载方式（就是shellcode加载器）现在常见的恶意代码基本都是dll的pe文件，不同的加载器方法就会对shellcode的加载和后期有不同的作用，一定要选择好。

##### 5---pe文件
PE（Portable Executable，可移植执行文件）是 Windows 可执行文件的格式，包括：

- **`.exe`（可执行文件）**
- **`.dll`（动态链接库）**
- **`.sys`（驱动程序）**

PE 文件的核心组成：

|结构|作用|
|---|---|
|DOS 头（MZ Header）|判断是否为 PE 文件|
|PE 头（NT Headers）|定义文件属性、入口点|
|节表（Section Table）|代码、数据存储位置|
|`.text` 节|可执行代码|
+----------------+
| MZ Header      |  # DOS 头
+----------------+
| PE Header      |  # PE 头
+----------------+
| .text Section  |  # 代码
+----------------+
| .data Section  |  # 数据
+----------------+

##### 6---最后关于shellcode的操作
可以发现这个组织木马加载器的加载逻辑是在通用加载器的基础之上创新产生的，在原有的加载方式上利用shellcode的加载再去解密出一个pe恶意文件，然后通过复制、抹去文件头等操作，最后在内存中加载高级远控木马。

##### 7---shellcode
**Shellcode** 是一段**用于控制目标系统的恶意代码**，通常以**汇编代码**编写，并用于**攻击漏洞、提权、远程执行代码**等目的。

- **“Shell”**：指的是系统 shell（如 `cmd.exe`、`bash`），也可以指控制系统的能力。
- **“Code”**：指的是这段代码的作用——让攻击者**获得目标系统的控制权**。

> **本质：** Shellcode 不是一种特定的病毒或木马，而是一种**执行恶意 payload 的代码**。

Shellcode 和木马（Trojan）的区别

| **对比项**    | **Shellcode**                | **木马（Trojan）**     |
| ---------- | ---------------------------- | ------------------ |
| **定义**     | 运行在漏洞利用、进程注入等情况下的一小段代码       | 伪装成正常软件，长期驻留目标系统   |
| **大小**     | 非常小，通常是几十到几百字节               | 可能是几百 KB 或几 MB     |
| **作用**     | 短期执行，如提权、打开反向 shell          | 长期驻留，远程控制、窃取信息     |
| **运行方式**   | 通过漏洞注入、缓冲区溢出、ROP 执行          | 通过用户下载运行           |
| **可执行形式**  | 机器码（通常是 **hex 格式** 或 **汇编**） | EXE、DLL、Python 脚本等 |
| **是否长期驻留** | 否，通常用于短时间执行恶意操作              | 是，通常用于持久化控制        |
