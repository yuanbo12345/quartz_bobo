# 第一遍：文献实验框架梳理
## 实验探究目的
<mark style="background: #FF5582A6;">通过机器学习算法加速可压缩燃烧模型（FPV）在超然冲压发动机模拟过程，同时减小计算过程中的内存占用</mark>

## 实验的框架
### ANN结构
1. 采用常规简单的三层网络模型，分别是：输入层（1层，负责输入多变量），隐藏层（5层堆成），输出层（1层）
2. 输入层输入变量参数：通过FlameMaster生成的层流火焰数据库取值，三个变量是反应进度变量，混合分数，混合分数方差
3. 隐藏层结构：16，32，64，32，16个神经元（对称结构）
4. 输出层：输出变量（反应物中各个组分的平均质量分数）
### 后续计算框架
1. ANN模型通过pytorch深度学习框架实现具体的代码编写
2. 通过pytorch的C++api接口库函数和OpenFOAM进行耦合，已把计算得到的反应物中各个组分的平均质量分数交给openfoam进行后续的数值计算
### 神经网络的具体结构激活函数
#### 激活函数 
 1. 采用ReLU（整流线性单元激活函数）
 2. 优势：该激活函数以及导函数均为单调函数，所以梯度为常数，与其他激活函数相比，<mark style="background: #FF5582A6;">该激活函数不需要指数计算，可以显著提高计算效率</mark>
 3. 原理就是，线性回归模型采用的拟合方法就是最大似然估计，而优化过程就是对定义的损失函数进行求导后，向梯度下降的方向前进（凸优化）去找极值点对应的就是最优解，对最大似然估计进行求导的过程需要先对数化，然后再求导
#### 损失函数
1. 采用了均方误差函数，由于评估每个周期的损失预测
2. 从经验来看，均方误差函数在计算损失函数的预测值和真实值之间误差遵从高斯分布
3. 代价函数：定义在整个训练集，表征损失函数的平均值

#### 优化器
1. 采用Adam方法适用随机梯度下降过程更新权重和偏置项（优化算法）

#### 训练过程
1. 每个组件都进行了100000个周期的训练
2. 初始学习率为0.001
3. 采用学习率调度程序（保证优化过程中随机的梯度下降造成下降步过长，模型收敛失效）

#### 相关性表示
1. 才用R表示预测值和真实值的相关性

# 第二遍：文献实验细节思考
## 实验创新点理解
了解basic的计算速度和内存占用减小的原因
1. 常规模拟不可压缩超然冲压发动机的方法是才用开源你的OpenFOAM平台进行数值计算，但是数值计算个核心是建立一系列符合物理过程的偏微分方程组，然后代入数值进行各种迭代的求解。方程组多，计算难度大，需要cpu核心数很高来进行并行的计算求解析解和数值解
2. 采用ANN网络本质就是建立符合物理约束的线性回归方程组，方程组结构简单，权重和偏置项系数都已经计算完毕，不需要再去迭代计算系数

## 实验选择的输入变量思考
### 选择变量原因
1. 实验选择了反应进度变量C，混合分数Z，混合分数方差Zn2
2. 该实验的数据来源于flamemaster的层流火焰数据库，通过这个数据库可以将湍流火焰假设为多个微小的层流火焰集合
3. flamemaster可以根据各种条件（压力，温度之类的工况参数）预先计算得出微小的基础层流火焰单元的详细化学反应和物理性质。然后将化学计算得到的数据存入多维的数据库中（本质就是进行化学反应计算的过程）
### 变量简介
1. 混合分数 (Mixture Fraction, Z)
   * 衡量什么： 燃料和氧化剂的混合状态，与化学反应是否发生无关。它只关心“混合得怎么样了”。
   * 物理意义： 混合分数是一个标准化的质量分数。它的定义是：在某个点，来自燃料气流的原子质量占总质量的比例。
       * Z = 1: 代表该点是纯燃料，还没有与任何氧化剂混合。
       * Z = 0: 代表该点是纯氧化剂（比如空气），还没有与任何燃料混合。
       * 0 < Z < 1: 代表燃料和氧化剂已经发生了混合。
   * 关键值 - 化学当量混合分数 (Z_st): 存在一个特定的Z值，叫做Z_st，代表燃料和氧化剂的混合比例恰好能完全燃烧，不多也不少。这是火焰温度最高、反应最剧烈的区域。

  2. 反应进度变量 (Reaction Progress Variable, C)
   * 衡量什么： 化学反应进行的程度。它描述了从“未燃烧的燃料/氧化剂混合物”到“完全燃烧的产物”这个过程走了多远。
   * 物理意义： 反应进度变量的定义方式有很多种，但最常见的思路是基于某种关键产物（如CO₂和H₂O）的质量分数或者温度来标准化。
       * C = 0: 代表该点是未燃烧的冷态混合物（虽然Z不为0，已经混合好了，但还没点燃）。
       * C = 1: 代表该点已经完全燃烧，达到了化学平衡状态，生成了最终产物。
       * 0 < C < 1: 代表反应正在进行中，是火焰的反应区。

  3. 混合分数方差 (Mixture Fraction Variance, Z_var 或 Z")
   * 衡量什么： 湍流对混合影响的强度，或者说是混合的不均匀程度。
   * 物理意义： 在湍流中，一个点的混合分数Z不是一个恒定值，而是在一个平均值附近剧烈波动。混合分数方差就是用来量化这种波动幅度的。
       * Z_var = 0: 代表该点是完全均匀的混合（或者根本没有湍流），这正是层流火焰的状态。
       * Z_var > 0: 代表该点混合不均匀，湍流很强，导致燃料和氧化剂的浓度在瞬时发生剧烈变化。Z_var越大，代表湍流脉动越强，混合越不均匀。个参数是连接理想“层流火焰单元”和真实“湍流环境”的关键桥梁。它主要影响平均的化学反应速率。
### 变量作用
在你的层流火焰数据库中，这三个变量构成了三个维度，像一个三维坐标系。数据库里存储的是在(Z, C,Z_var)每一个坐标点上对应的其他物理量（如温度、组分浓度、反应速率等）。

   * 混合分数 (Z) - 决定了“原料”:它告诉你，在某个位置，<mark style="background: #FF5582A6;">燃料和空气的平均比例是多少。这个比例决定了燃烧的“潜力”</mark>，比如它能达到的最高温度（绝热火焰温度）和最终的产物成分。这是最基本的维度。

   * 反应进度变量 (C) - 决定了“过程”:对于一个给定的混合比例Z，<mark style="background: #FF5582A6;">它告诉你反应进行到哪一步了</mark>。例如，一个化学当量混合物（Z=Z_st），可能是完全未燃（C=0），也可能是正在剧烈反应的（C≈0.5），或者是已经烧完的（C=1）。它<mark style="background: #FF5582A6;">描述了火焰从点燃到熄灭的整个生命周期</mark>。


   * 混合分数方差 (Z_var) - 决定了“环境影响”:它代表了湍流对化学反应的平均效应。对于给定的平均混合物(Z)和平均反应进度(C)，<mark style="background: #FF5582A6;">湍流的强度(Z_var)会影响局部的真实反应速率</mark>。例如，强烈的湍流脉动（高Z_var）可能会导致火焰局部瞬时过浓或过稀，从而使平均反应速率降低，甚至导致火焰熄灭。<mark style="background: #FF5582A6;">它是一个对理想层流火焰在湍流环境下的修正参数。</mark>

 1. 首先，用Z找到对应的燃料-空气混合比。
   2. 然后，用C在Z对应的这条线上，找到反应进行到了哪个阶段。
   3. 最后，用Z_var来考虑湍流波动对这个状态的影响，对结果（比如平均反应速率）进行修正。
  通过这三个变量的组合，你的数据库就能够以较低的计算成本，相对准确地描述出复杂湍流燃烧中的各种状态。

## 实验数据集
1. 实验数据集来自于通过flamemaster输入不同工况下进行微小层流火焰的化学反应计算
2. 该计算可以将微小层流火焰单元的反应计算结果经过旋转等处理得到湍流火焰的化学反应计算结果
### 实验中数据特性及分布规律
由于实验采用的ANN是建立在常规工况下湍流火焰的化学反应线性回归预测过程，并且只包含一个输出变量，所以没有探究输出变量之间的分布关系已进行后续的数据生成或者采样处理

1.  输入变量之间的标准化处理
2. 由于数据集采用开源函数库计算得到，所以数据不用进行降噪处理
3. 对所有输入变量进行归一化处理，将输入变量的元素值均控制在【0-1】范围之内
4. 归一化处理可以去除物理量纲的影响，以免网络在学习过程中将大量纲的变量作为主要特征学习，忽略小量纲的变量影响（简单讲就是平衡输入变量之间的权重关系）
### 训练过程
#### 数据集划分问题
1. 没有在文献中观察到关于数据集划分的问题
2. 常规数据集要进行定量的划分，通常为：训练集>验证集>测试集，将整个数据集分成三大模块，每个模块具体的数据量要在符合大小关系下随机划分，避免多次学习同样内容，以及测试集统一造成的模型收敛过快，泛化能力过差
3. 训练集采用多批次，小批量的进行训练。可以增加反向传播过程的梯度优化精度，提升模型的拟合能力（实验采用了100000周期）
4. 学习率设置，代表了梯度的下降速度，设置过快会造成，错过全局最优解，陷入局部最优解的过程，常规设置为：0.001

##### 回归曲线图
作用：图中含有y=x的基础回归线，x代表网络计算得出的预测值，y代表数据库中的真实值，然后曲线表示预测值和真实值完全相同的情况，即误差为零，当你的网络做出的预测值和真实值之间形成的回归曲线更加靠近该曲线时，就证明你的模型的准确度很好
