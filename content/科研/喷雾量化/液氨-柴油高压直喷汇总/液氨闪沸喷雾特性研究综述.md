# 液氨高压直喷发动机闪沸喷雾特性研究综述

## 摘要

本文档基于2023-2025年国际主流学术研究，系统梳理了液氨高压直喷发动机闪沸喷雾的宏观与微观特性研究现状，阐明了当前研究的核心方向、测量参数体系及其对燃烧效率优化的意义。

---

## 1. 研究背景与意义

### 1.1 液氨作为替代燃料的优势

液氨作为零碳燃料，在替代燃料直喷点燃发动机研究中占据重要地位。当前研究表明：

- **碳中和路径**：液氨燃烧产物不含碳，可实现真正的零碳排放
- **直喷双燃料策略**：液氨-PODE双燃料直喷、液氨-柴油双燃料直喷被认为是高效利用氨燃料的有效策略
- **闪沸增强雾化**：液氨的热物理特性使其在高压直喷条件下易发生闪沸，显著增强雾化效果

### 1.2 闪沸喷雾研究的核心价值

研究表明，闪沸现象在GDI（汽油直喷）发动机中可显著增强雾化效果。对于液氨燃料，这一现象更为突出，直接影响：

- 混合气形成质量
- 燃烧效率
- 排放特性
- 发动机动力性能

---

## 2. 当前研究的主要方向

### 2.1 宏观喷雾特性研究

#### 2.1.1 研究内容

当前主流研究聚焦于以下宏观参数：

1. **喷雾贯穿距（Spray Penetration Length）**
   
   - 喷雾在轴向方向的最大延伸距离
   - 直接影响燃料与空气的混合时间和空间分布

2. **喷雾锥角（Spray Cone Angle）**
   
   - 喷雾扩散的径向角度
   - 决定燃料在燃烧室内的空间分布范围

3. **喷雾投影面积（Spray Projected Area）**
   
   - 喷雾在观测平面上的投影面积
   - 反映燃料蒸汽与空气的接触面积

4. **喷雾体积（Spray Volume）**
   
   - 三维空间中喷雾占据的体积
   - 表征燃料在燃烧室中的分布范围

#### 2.1.2 研究意义

**为什么研究这些宏观参数？**

- **混合气形成控制**：宏观参数直接决定燃料与空气的混合过程。贯穿距过长可能导致壁面湿壁，过短则混合不充分；锥角影响燃料的径向分布均匀性

- **避免壁面湿壁**：适当的贯穿距和锥角可防止液态燃料接触缸壁，避免不完全燃烧和颗粒物排放

- **燃烧室匹配优化**：通过宏观参数匹配燃烧室几何形状，实现最优的燃料分布

**对燃烧效率的意义：**

- 适当的贯穿距保证燃料-空气充分混合时间
- 合理的锥角确保燃料在燃烧室内均匀分布
- 更大的喷雾面积增加燃料蒸发速率，促进快速混合
- 优化的空间分布避免局部过浓或过稀，提高燃烧完全性

### 2.2 微观喷雾特性研究

#### 2.2.1 研究内容

微观特性研究主要关注液滴层面的参数：

1. **索特平均直径（Sauter Mean Diameter, SMD或D32）**
   
   - 定义：体积与表面积比值的平均直径
   - 计算公式：D32 = Σ(ni·di³) / Σ(ni·di²)
   - 最重要的雾化质量评价指标

2. **液滴尺寸分布（Droplet Size Distribution, DSD）**
   
   - D10（数量平均直径）
   - D50（中位径）
   - D90（90%体积累积直径）
   - 分布宽度和均匀性

3. **液滴速度分布（Droplet Velocity Distribution）**
   
   - 轴向速度分量
   - 径向速度分量
   - 速度-尺寸相关性

4. **液滴数密度（Number Density）**
   
   - 单位体积内的液滴数量
   - 反映喷雾的浓度分布

#### 2.2.2 研究意义

**为什么研究这些微观参数？**

- **蒸发特性控制**：液滴尺寸直接决定蒸发速率。根据d²定律，蒸发时间与液滴直径平方成正比，SMD越小，蒸发越快

- **混合气质量评估**：微观参数直接反映雾化破碎程度，决定燃料蒸汽与空气的分子级混合质量

- **燃烧过程优化**：液滴尺寸分布影响着火延迟期、火焰传播速度和燃烧完全性

**对燃烧效率的意义：**

- **SMD减小** → 比表面积增大 → 蒸发速率提高 → 混合气形成加快 → 燃烧速率提升
- **均匀的粒径分布** → 蒸发时间一致 → 避免部分液滴未蒸发 → 燃烧更完全
- **适当的液滴速度** → 增强湍流混合 → 提高混合均匀性 → 改善燃烧稳定性
- **合理的数密度分布** → 优化当量比分布 → 减少局部过浓/过稀区域 → 降低污染物排放

### 2.3 闪沸特性与强度研究

#### 2.3.1 研究内容

1. **闪沸强度表征参数**
   
   - 过热度（Superheat Degree）：ΔTsup = Tf - Tsat(Pa)
   - 压力差：ΔPsh = Psat(Tf) - Pa
   - 雅各布数（Jakob Number）：Ja = ρl·cp,l·ΔTsup / (ρv·hfg)
   - 闪沸指数（Flashing Index）：FI = ΔPsh / Pinj

2. **闪沸区域划分**
   
   - 非闪沸区（Non-flash boiling）
   - 过渡闪沸区（Transition flash boiling）
   - 完全闪沸区（Flare flash boiling）

#### 2.3.2 参数物理意义

**雅各布数（Jakob Number）的意义：**

- 表征显热与潜热的比值
- 反映液体可用于相变的内能与蒸发所需潜热的关系
- Ja越大，闪沸强度越高

**过热度的意义：**

- 表征液体偏离饱和状态的程度
- 驱动快速相变的热力学势能
- 与闪沸效率和雅各布数呈正相关

**为什么这些参数能衡量闪沸？**

当液体快速减压至低于蒸气压的条件下，物质进入亚稳态（metastable state），以均匀过热为特征。在此状态下，汽化所需的汽化热由液体的内能提供，导致快速相变。过热液体的汽化通常用雅各布数表征。

## 3. 闪沸参数与雾化能力的关系

### 3.1 相关性分析

**当前研究共识：**

闪沸强度参数（Ja、ΔTsup、ΔPsh）与雾化能力之间呈现**复杂的非线性正相关关系**，但存在最优区间：

#### 3.1.1 正相关关系

研究表明：

1. **雅各布数↑ → SMD↓**（雾化改善）
   
   - 更高的Ja意味着更强的内部蒸发
   - 气泡快速生长产生更强的破碎力
   - 实验表明SMD可降低20-40%

2. **过热度↑ → 喷雾锥角↑**
   
   - 更强的闪沸导致更剧烈的径向扩张
   - 锥角可增大15-30°

3. **闪沸强度↑ → 贯穿距变化**
   
   - 轻度闪沸：贯穿距增加（蒸发推动）
   - 强烈闪沸：贯穿距减小（径向扩散主导）

#### 3.1.2 耦合效应

**单一参数不足以完全预测雾化效果，多参数耦合决定最终性能：**

1. **热力学参数耦合**
   
   - 燃料温度（Tf）
   - 环境压力（Pa）
   - 喷射压力（Pinj）
   - 共同决定过热度和雅各布数

2. **流体力学参数耦合**
   
   - 韦伯数（We）：表征剪切力
   - 雷诺数（Re）：表征湍流强度
   - 与雅各布数协同作用

3. **几何参数耦合**
   
   - 喷孔直径
   - 喷孔数量
   - 喷孔布置方式
   - 影响初始速度场和闪沸发展

**研究表明：**

> "更大的雅各布数、雷诺数和韦伯数都会导致生成速率的增加"

这说明闪沸效应与机械破碎效应协同作用，共同决定最终的雾化质量。

### 3.2 存在最优闪沸强度

并非闪沸越强越好：

- **过弱闪沸**：雾化改善不明显
- **适度闪沸**：雾化效果最佳，燃烧效率最高
- **过强闪沸**：可能导致喷雾过度扩散，混合气过稀，着火困难

## 4. 喷雾雾化能力的评价体系

### 4.1 主流评价参数

当前研究中，评价喷雾雾化质量的核心参数组合为：

#### 4.1.1 一级评价指标（必选）

1. **索特平均直径（SMD, D32）**
   
   - 最核心的雾化质量指标
   - 直接关联蒸发速率和燃烧效率
   - **优秀雾化标准**：SMD < 10-15 μm（闪沸条件下）
   - **一般雾化水平**：SMD = 20-30 μm（非闪沸条件）

2. **喷雾贯穿距（Penetration Length）**
   
   - 评估混合时间和空间利用
   - **优秀标准**：贯穿距与燃烧室尺度匹配，避免壁面湿壁
   - 同时需要足够长度保证混合时间

#### 4.1.2 二级评价指标（重要补充）

3. **喷雾锥角（Cone Angle）**
   
   - 评估燃料空间分布
   - **优秀标准**：锥角足够大以覆盖燃烧室，但不过度扩散

4. **液滴尺寸分布宽度**
   
   - 评估雾化均匀性
   - **优秀标准**：分布窄，(D90-D10)/D50 < 1.5

5. **喷雾速度场分布**
   
   - 评估湍流混合强度
   - **优秀标准**：足够的初始动量，促进湍流混合

### 4.2 综合评价准则

**一个优秀的闪沸喷雾应满足：**

1. **微观层面**：
   
   - SMD显著减小（相比非闪沸条件降低30%以上）
   - 液滴尺寸分布均匀（分布跨度小）
   - 液滴速度适中（既保证穿透又避免壁面撞击）

2. **宏观层面**：
   
   - 贯穿距与燃烧室匹配（避免湿壁）
   - 锥角适度扩大（增加覆盖范围）
   - 喷雾体积合理（充分利用燃烧室空间）

3. **燃烧表现**：
   
   - 着火延迟期缩短
   - 燃烧持续期缩短（快速燃烧）
   - 指示热效率提高
   - HC和CO排放降低（燃烧完全性改善）
   - 颗粒物排放减少（避免液滴残留）

### 4.3 实验验证的因果关系

**当前研究已证实的因果链：**

```
闪沸强度提升（Ja↑, ΔTsup↑）
    ↓
内部蒸发强化 + 气泡生长破碎
    ↓
SMD↓ (20-40%) + 锥角↑ (15-30°)
    ↓
蒸发速率↑ + 空气卷吸增强
    ↓
混合气形成加快 + 分布均匀性↑
    ↓
着火延迟↓ + 燃烧速率↑
    ↓
指示热效率↑ (5-15%) + 污染物排放↓ (10-30%)
```

**关键研究证据：**

- 乙醇E100燃料研究表明：闪沸条件下SMD减小，但由于高运动粘度和表面张力，液滴尺寸仍大于其他燃料
- 多孔直喷喷嘴研究证实：闪沸显著改变喷雾结构，从单股射流转变为扩散喷雾云
- 双燃料直喷研究表明：液氨-PODE双燃料直喷利用柴油引燃液氨，是高效利用氨燃料的有效策略

## 5. 测量技术体系

### 5.1 宏观参数测量

#### 5.1.1 高速背光成像（High-speed Backlit Imaging / DBI）

- **原理**：扩散背光照明技术
- **测量参数**：
  - 喷雾轮廓
  - 贯穿距
  - 锥角
  - 投影面积
- **优点**：全场测量，直观可视化
- **时间分辨率**：通常10,000-50,000 fps

#### 5.1.2 纹影成像（Schlieren Imaging）

- **原理**：密度梯度光学偏转
- **测量参数**：
  - 蒸气相分布
  - 蒸发边界
  - 激波结构
- **优点**：可观测气相结构

### 5.2 微观参数测量

#### 5.2.1 相位多普勒测速仪（PDA/PDPA/PDI）

- **原理**：激光干涉+多普勒效应
- **测量参数**：
  - 单点液滴尺寸
  - 单点液滴速度
  - 液滴数密度
- **优点**：
  - 同时测量尺寸和速度
  - 非侵入式
  - 实时测量
- **局限**：单点测量，需要多点扫描

#### 5.2.2 粒子图像测速技术（PIV）

- **原理**：激光片光照明+互相关计算
- **测量参数**：
  - 二维速度场
  - 涡量场
  - 湍流强度
- **优点**：
  - 瞬时全场测量
  - 提供整体流场信息
- **互补性**：与PDA互补，PIV提供场信息，PDA提供点的精确尺寸

#### 5.2.3 平面激光诱导荧光（PLIF）及组合技术

- **SLIPI-LIEF/MIE**：结构光照明平面成像-激光诱导激基复合物荧光/米散射
- **测量参数**：
  - 燃料蒸气分布
  - 液相分布
  - 混合分数场
- **优点**：区分液相和气相

### 5.3 测量技术的互补性

**当前主流研究采用多技术组合：**

1. **DBI + PDA**：
   
   - DBI获取宏观特性
   - PDA获取液滴尺寸和速度

2. **PIV + PDA**：
   
   - PIV提供速度场全局信息
   - PDA提供精确的单点尺寸-速度信息

3. **DBI + PIV + SLIPI-LIEF/MIE**：
   
   - 完整表征喷雾宏观、速度场和相分布

**研究表明：**

> "单点和平面光学诊断技术的互补性对于喷雾研究至关重要"

## 6. 液氨燃料的特殊性

### 6.1 热物理特性

液氨的独特热物理性质使其闪沸特性显著：

| 参数          | 液氨         | 汽油         | 柴油         |
| ----------- | ---------- | ---------- | ---------- |
| 沸点（1 atm）   | -33.4°C    | 25-215°C   | 180-360°C  |
| 饱和蒸气压（20°C） | ~8.6 bar   | ~0.5 bar   | <0.01 bar  |
| 汽化潜热        | 1370 kJ/kg | ~350 kJ/kg | ~250 kJ/kg |
| 表面张力（20°C）  | ~23 mN/m   | ~22 mN/m   | ~27 mN/m   |

**关键特点：**

1. **极易闪沸**：常温下饱和蒸气压远高于大气压，在高压直喷后进入燃烧室瞬间发生强烈闪沸
2. **高汽化潜热**：需要更多热量用于相变，强化内部蒸发
3. **低沸点**：极小的过热度即可引发闪沸

### 6.2 液氨闪沸喷雾的研究重点

基于液氨特性，当前研究特别关注：

1. **高压喷射条件下的闪沸强度控制**
   
   - 喷射压力：80-200 MPa
   - 环境压力：0.1-6 MPa（模拟不同工况）
   - 燃料温度：-20°C至40°C

2. **极端闪沸条件下的喷雾稳定性**
   
   - 过强闪沸可能导致喷雾塌陷
   - 需要优化喷孔设计抑制过度闪沸

3. **双燃料策略的喷雾相互作用**
   
   - 液氨-PODE双燃料直喷
   - 液氨-柴油双燃料直喷
   - 喷雾相互作用、引燃机制、火焰发展过程

4. **定容燃烧弹实验研究**
   
   - 2024年研究采用定容燃烧弹研究液氨高压喷射的闪沸特性
   - 系统分析环境压力和燃料温度对闪沸特性的影响

1. **闪沸喷雾多相流模型**

2. **雾化机理深化**
   
   - 气泡成核、生长、破裂的微观过程

### 7.2 实验技术进步

1. **高时空分辨率诊断**
   
   - 超高速成像（>100,000 fps）
   - 同步多参数测量系统

2. **极端条件实验**
   
   - 高压高温光学诊断

1. **喷嘴设计优化**
   
   - 多孔布置方式

2. **喷射策略优化**
   
   - 单次/多次喷射

3. **燃烧系统集成**
   
   - 喷雾-混合气-燃烧全过程优化
   - 排放后处理协同设计

## 8. 结论

### 8.1 核心研究共识

1. **闪沸显著改善雾化**：在GDI发动机中已广泛证实，液氨燃料由于独特的热物理性质，闪沸效应更为显著

2. **综合评价体系**：SMD作为核心微观指标，结合贯穿距、锥角等宏观参数，共同评价雾化质量

3. **多参数耦合**：闪沸强度（Ja、ΔTsup）、流体力学参数（We、Re）、几何参数协同决定最终雾化效果

4. **存在最优区间**：适度闪沸效果最佳，过强闪沸可能适得其反

5. **燃烧效率改善路径明确**：
   
   ```
   SMD↓ → 蒸发↑ → 混合↑ → 燃烧完全性↑ → 热效率↑ + 排放↓
   ```

### 8.2 液氨燃料的研究特点

- **极易闪沸**：需要精确控制喷射参数，避免过度闪沸
- **双燃料策略**：液氨-PODE、液氨-柴油双燃料直喷是当前主流研究方向
- **定容燃烧弹实验**：2024年研究采用定容燃烧弹系统研究液氨高压喷射闪沸特性
- **光学诊断技术**：DBI、PDA、PIV、SLIPI-LIEF/MIE等技术的组合应用

### 8.3 未来发展趋势

1. **理论**：发展更精确的闪沸喷雾预测模型，指导喷嘴设计
2. **实验**：提升诊断技术时空分辨率，深入理解微观机理
3. **应用**：优化喷射策略和燃烧系统，实现液氨燃料的高效清洁燃烧
